# Microservices Architecture Study

> [『스프링 마이크로서비스 코딩 공작소 (Spring Microservices in Action)』](https://wikibook.co.kr/spring-microservice/) 학습 및 실습 코드 저장소입니다.

## 소개 (Introduction)
이 저장소는 스프링 부트(Spring Boot)와 스프링 클라우드(Spring Cloud)를 활용하여 클라우드 네이티브 마이크로서비스 아키텍처(MSA)를 설계, 구축, 배포하는 전체 과정을 학습하며 작성한 예제 코드와 개념 정리 노트를 관리합니다.

## 기술 스택 (Tech Stack)

### Backend
* **Language:** Java 21
* **Framework:** Spring Boot 4.0.8

### Spring Cloud Ecosystem
* **Configuration Management:** Spring Cloud Config
* **Service Discovery:** Spring Cloud Netflix Eureka
* **API Gateway:** Spring Cloud Gateway
* **Client Resiliency:** Resilience4j (Circuit Breaker, Bulkhead, Retry, Rate Limiter)
* **Event-Driven Architecture:** Spring Cloud Stream (Kafka / RabbitMQ)
* **Distributed Tracing:** Spring Cloud Sleuth, Zipkin
* **Security:** Keycloak, Spring Cloud Security

### Infrastructure & DevOps
* **Containerization:** Docker, Docker Compose
* **Database:** PostgreSQL, Redis
* **Monitoring:** Prometheus, Grafana
